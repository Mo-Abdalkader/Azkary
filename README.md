## About

**أذكاري** is a Progressive Web App (PWA) for daily Islamic azkar (remembrances) and duas (supplications). It works offline, can be installed on your phone's home screen, and provides a smooth, app-like experience.

### Features

- **Morning & Evening Azkar** — curated collections for sunrise and sunset
- **Daily Duas** — categorized supplications for every occasion (rizq, protection, forgiveness, family, study, Ramadan, Arafah, and more)
- **Digital Tasbeeh** — tap-based counter with long-press reset
- **Dark & Light Themes** — automatic or manual toggle
- **Search** — find any dua instantly
- **Favorites** — bookmark your most-used duas
- **Fully Offline** — service worker caches everything on first visit
- **Installable** — add to home screen on Android & iOS
- **RTL** — full right-to-left Arabic interface

## Tech Stack

- **Vanilla JS** — no frameworks, lightweight
- **CSS Custom Properties** — themeable dark/light mode
- **Service Worker** — offline-first caching
- **Manifest** — PWA installable
- **Google Analytics** — usage tracking
